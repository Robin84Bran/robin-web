# Google Cloudは倍増した。株主は何を得たのか？

AlphabetはGoogleの親会社であり、さまざまな方法で人や企業にサービスを届け、収益を得ている。Google Cloudは、計算能力、ストレージ、データ処理、人工知能サービスを必要とする組織を支える。顧客はGoogleが建設・運用する計算資源をネットワーク経由で使い、利用量に応じて支払う。これがクラウドコンピューティングである。

この事業の一部は継続利用や購読から売上高を生む。AlphabetはTPU（テンソル処理装置）を中心に構築した完成システムも販売する。TPUはAI処理向けの専用チップであり、1つのシステムを納入すると、大きな売上高が1四半期に計上されることがある。

発電機を1台丸ごと販売しながら、別の顧客には継続して電気を供給する公益企業を考えると分かりやすい。発電機は引き渡し時に売上高を生み、電力は顧客が使い続ける間、料金を生む。どちらも価値ある事業になり得るが、収益のリズムと必要な投資は異なる。この違いが、Google Cloudの成長構成を確認する理由になる。

2026年10月28日、AlphabetはGoogle Cloudの四半期売上高が2倍以上になったと発表した。この増加が株主にとって何を意味するかを理解するには、Cloudの売上高と営業利益から、親会社の支出、資金調達、現金支払いまでを追う必要がある。

### 大きくなったCloud事業

決算の対象は9月30日までの第3四半期だった。Alphabetの詳細なForm 10-Qは10月28日遅くに米国証券取引委員会に受理され、10月29日に提出された。

Alphabet全体の売上高は前年同期比25%増の1,275億7,700万ドルだった。Google Cloudはさらに速く成長し、売上高は151億5,700万ドルから307億900万ドルへ103%増加した。

Alphabetは、企業向けAIインフラ、企業向けAIソリューション、基礎的な計算サービスを含むGoogle Cloud Platformが増加を主導したと説明した。TPUシステム販売も大きく寄与した。複数の成長源は示されたが、正確な構成比は開示されていない。307億900万ドルにはシステム販売、継続サービス、その他のCloud事業が含まれ、継続サービスが占める割合は未確定である。

機器を集中的に納入した四半期と、サービス利用が継続的に伸びた四半期では、将来の売上高について得られる手掛かりが異なる。追加の機器注文は顧客の購入計画に左右され、利用収入は顧客が計算資源を使い続けるかで決まる。どちらも成長し得るが、それぞれ違うパターンを持つ。

Cloudの営業利益は前年同期の35億9,400万ドルから111億2,100万ドルへ大幅に増えた。営業利益は、Alphabetの会計上、その事業に配分された営業費用を差し引いた後に残る金額である。Cloudは売上高の拡大とともに大きな営業利益を生んだ。

これは事業の運営実績を示す前向きな証拠である。株主にとって次の問いは、この会計上の利益がAlphabetの生んだ現金と、インフラに支払った現金にどうつながるかである。

### 成長を支える現金

インフラと、その上で動くサービスでは時間の流れ方が違う。企業は何年も顧客に使われる設備を先に建設する。会計では長期資産の費用を使用期間に配分する一方、購入時に出ていく現金は設備投資として記録する。

この時間差により、強い営業利益と大きな現金需要が同時に現れる。Alphabet全体では、第3四半期に営業活動から423億ドルの現金を生み、主に技術インフラに514億ドルの設備投資を行った。

Alphabetはフリーキャッシュフローを、営業キャッシュフローから設備投資を引いた金額と定義する。公表された調整表では、第3四半期のフリーキャッシュフローは90億6,500万ドルのマイナスだった。長期資産への支出が営業活動で生んだ現金を上回ったという意味である。

数字の範囲は明確に分ける必要がある。111億2,100万ドルの営業利益はGoogle Cloud部門の数字だが、キャッシュフローと設備投資はAlphabet全社の数字である。514億ドルは会社全体の投資であり、Cloudだけの負担額は開示されていない。

Cloudの会計は、より大きな事業と急増した営業利益を示す。Alphabetの現金勘定は、この四半期に営業活動の現金創出を上回る速度で投資した会社を示す。将来の顧客需要とインフラが稼ぐ収益が、支出の生産性を決める。1四半期の報告は現在の支出と事業実績を捉えるが、投資の回収はより長い期間にわたる。

### 株主が受け取り、資金を支えたもの

株主が受け取った直接の現金は、Alphabetが四半期中に支払った27億ドルの普通株配当だった。

同時に、会社は貸し手と株式購入者から資金を集めた。Alphabetは優先無担保社債を発行し、一般的な企業目的に使うため、純額287億ドルを調達した。

さらにA株1,200万株を発行して純額43億ドル、C株2,400万株を発行して純額81億ドルを得た。四半期報告書によると、この市場価格による株式売却プログラムは、主に従業員への株式報酬に伴う税負担を支える。9月30日時点で276億ドルの追加発行枠が残っていた。

借入金は一般的な企業用途の資金となり、株式売却プログラムは主として株式報酬に関する税負担を支え、配当は株主へ現金を届けた。いずれもAlphabet全社の財務に属するため、特定額をCloudに割り当てるには会社による追加開示が必要となる。

従業員報酬も考慮に入る。Alphabetは四半期に87億ドルの株式報酬費用を計上し、そのうち83億ドルはAlphabet株で決済される見込みの報酬だった。株式数が増えると、他の条件が同じなら、既存の1株が表す会社の持分は小さくなる。株式発行は会社に資源をもたらし、株式報酬は従業員への支払いにもなる。1株の最終価値は、会社の価値と現金創出力が株式数に対してどう伸びるかで決まる。

### 1四半期を超える約束

Alphabetの投資期間はこの決算から何年も先まで延びている。会社は将来の重要な購入契約を9,244億ドル開示した。そのうち8,021億ドルは、技術インフラと在庫、エネルギーのテイク・オア・ペイ契約、コンテンツライセンスを対象とする。テイク・オア・ペイでは、実際の利用量が契約量を下回っても、買い手が合意額を支払うのが一般的である。購入契約の大部分は2031年まで続く。

Alphabetは別に、開始前のリース契約1,305億ドルも開示した。主な対象はデータセンターとエネルギーインフラである。これらの将来契約は、第3四半期に支払った514億ドルの設備投資とは時期も会計処理も異なる。合わせて見ると、計画された義務の規模と期間が分かる。

Google Cloudの倍増は報告された会計上の事実であり、営業利益も大きく増えた。株主は配当を受け取り、Alphabetは多額の現金を投じ、会社全体で追加資金を調達した。

残る問いは、売上高の構成から投資期間まで広がる。Cloudの拡大した売上高のうち、どれだけが継続し、Alphabetの拡大するインフラは最終的に1株当たりどれだけの持続的な現金を生むのだろうか。
