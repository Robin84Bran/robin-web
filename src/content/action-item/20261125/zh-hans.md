# 如果 SpaceX 收购 Tesla，谁会多一票？

SpaceX 与 Tesla 分别建设着埃隆·马斯克所期望的未来的不同部分。SpaceX 经营发射、卫星、通信及 AI 相关业务；Tesla 制造电动汽车、能源产品和机器人系统。马斯克同时担任两家公司的首席执行官，将这两家公司联系在一起，而两边的股东拥有各自独立的财务利益，对公司决策也有不同的权力。

合并会把这些差异带到同一场谈判中。Tesla 股东会关心对方为其公司提供的价值；SpaceX 股东会关心自己的公司为收购付出什么。如果付款包含 SpaceX 股份，交易还会分配一种具有持久重要性的东西：投票权。

因此，这是一个关于所有权如何运作的故事。一股股票赋予持有人一份企业的经济权益。其投票权则帮助决定，持有人对提交股东表决的事项有多少发言权，其中包括选举董事。在 SpaceX，股份类别会让这种发言权产生很大差异。

合并的可能性如今已经进入董事会正式评估阶段。截至香港时间2026年11月25日，公开记录描述的是一个探索过程。两家公司是否会达成协议、条款可能是什么，以及交易能否完成，都仍未有定论。

要理解股东可能获得什么，可以先从公司申报文件已经描述的投票安排看起。

SpaceX 日期为2026年6月1日的修订版招股书列出了两类有投票权的普通股。每股 A 类股有一票，每股 B 类股有十票。这种安排称为双重股权结构：所有权以两种形式存在，投票力量各不相同。

B 类股还拥有另一项独立权力。只要仍有任何 B 类股在外流通，其持有人就能作为一个类别共同投票，选出 SpaceX 董事会的51%。这让该类别除了拥有更大的票数权重，还能通过另一条途径选出董事会多数席位。招股书也描述了转让规则：除规定的允许转让情形外，B 类股转让时通常会转换为 A 类股。

举例来说，想象一个发行会员资格的俱乐部。每份会员资格都赋予持有人一份俱乐部权益，但一种资格附带一张选票，另一种附带十张。拥有十张选票的会员还负责选出略多于一半的管理委员会成员。计算会员资格数量，能告诉你一些关于所有权的情况；计算选票并阅读委员会选举规则，才知道谁能掌舵。

SpaceX 招股书提供了一个注明日期的快照，显示这些票数曾有多集中。其受益所有权表报告，截至2026年5月1日、发行前，马斯克持有合并投票权的85.1%。这是发行前的快照，有其特定日期和背景。

Tesla 的2026年委托投票文件则提供了另一类快照。其受益所有权表使用9月30日的股份数据，列出马斯克受益持有699,580,882股，所有权比例为19.8%。“受益所有权”是一种申报类别，用于按披露规则识别归属于某人的持股；该表及其脚注解释了这个数字涵盖的范围。Tesla 的脚注把马斯克2025年 CEO 奖励中的另外423,743,904股限制性股份排除在表内他的投票控制范围之外，因为这些股份受一份投票协议约束。

因此，这两个醒目的百分比描述的是不同时间的不同事物：SpaceX 发行前的合并投票权，以及 Tesla 较晚时点的受益所有权比例。两者都有助于解释起点。要计算未来合并后的控制权，需要拟议交易的条款，以及口径一致的所有权信息。

在这一背景下，两家公司的季度申报文件让潜在合并进入公众视野。

SpaceX 在截至2026年9月30日季度的 Form 10-Q 中表示，董事会已成立特别委员会，评估与 Tesla 潜在合并的可能性。Tesla 对应的申报文件称，董事会已成立由无利害关系董事组成的特别委员会，探索与 SpaceX 更深入的关系，其中可能包括业务合并。

这些委员会之所以重要，是因为马斯克同时在双方担任职务。买方股东通常希望以有吸引力的条件获得一家企业；卖方股东通常希望获得有吸引力的价值。共同的首席执行官带来了需要董事会管理的关联方利益冲突。各自设立委员会，为审视两家公司股东的利益提供了程序。任何最终条款是否公平、谈判结果如何，仍是这个程序需要回答的问题。

11月24日，*《金融时报》*报道，Tesla 三名董事及 SpaceX 两名董事在谈判委员会中任职。路透社重复了三人和两人的数字，并注明消息来自*《金融时报》*。这个区分很有用：公司申报文件证实评估程序存在，而委员会成员的细节来自新闻报道。

申报文件还描述了批准要求。SpaceX 称，合并需要其特别委员会、董事会及控股股东进一步批准。Tesla 称，交易需要其特别委员会的肯定性推荐，以及任何必要的股东批准。

所以，标题中的“如果”分量很重。截至11月25日的截稿时点，在已审阅的公开记录中，收购价、支付组合、换股比例，以及任何用于支付的股份类别都尚未确定。能否达成协议、完成交易，仍然不确定。

故事由此来到一个实际问题：如果 Tesla 股东收到 SpaceX 股份，他们会同时获得多少所有权，以及多少发言权？

以股份支付的交易会同时改变两本账。一本记录经济所有权：每位持有人拥有合并后企业的多少份额。另一本记录投票权：每位持有人能投多少票，以及这些股份附带哪些选举权。

看一个简单的算术示例。将新发行 SpaceX 股份的数量固定为十亿股。如果是 A 类股，就会增加十亿票；如果是 B 类股，就会增加一百亿票。这是对现行投票规则的示例说明，与两家公司的谈判以及对谈判条款的任何预测都无关。

接收者同样重要。如果按比例向 Tesla 持有人分配股份，每个人的分配量将依据换股比例，也就是每股 Tesla 股票可换得多少股买方股票。这份分配所带来的投票权，取决于收到的股份类别及其适用规则。

马斯克的持股让这一点尤其相关。作为两家公司的持有人，他可能已经在买方持有权益，同时又因卖方符合条件的持股而获得对价。其他投资者也可能同时持有两家公司的股票。新股发行会扩大股份总池，而接收者可能在原有持股之上继续增加。对任何人控制权的最终影响，都取决于这两种变化。

这就是为什么收购价只能说明故事的一部分。价格描述的是所提供的价值。股份数量、换股比例、投票类别、转换规则及接收者，则解释股份支付如何重新分配所有权和影响力。批准要求会明确提案需要谁的同意。

目前，具体进展是两家董事会正式展开评估，随后媒体报道了谈判委员会的细节。未来的提案，才会把宽泛的可能性变成股东能够审视的条款。

当这些条款出现时，谁会多一票，将取决于几个朴素的问题：发行哪一类股份、发行多少、谁来接收，以及需要谁批准？
