# 生成一段视频花1.05美元，讲好一个故事还要算更多账

一段短视频可以成为一篇长文章的入口。十五秒里，它可以介绍一台机器，说明一项商业决策为何重要，也可以让观众愿意继续读下去。要做好这个入口，编辑得挑选事实、决定从哪里讲起、制作画面、核对画面传达的意思，再把作品送到观众面前。

Google DeepMind 是 Google 旗下开发本文所述视频模型的团队。2026年11月5日，Google 发布了用于生成和编辑短视频的 Gemini Omni 1.2 Flash。根据发布公告，该模型已通过 Gemini API 和 Google Cloud 正式向用户开放；Gemini API 让软件能够接入模型。

按公布的价格，生成一段十五秒、720p 的视频，费用是1.05美元。重试、编辑和分发的费用另算。这个数字很醒目，关键在于看清它买到的是什么：一次视频生成。

“生成一秒”指模型产出一秒视频。Google 公布的720p价格是每生成一秒0.07美元；720p 指画面在垂直方向有720行像素。十五秒乘以0.07美元，正好是1.05美元。每多试一次，账单就会增加相应的生成秒数，即使编辑最后弃用了那段画面。

乘法很简单。围绕这段视频展开的工作，才是更值得细看的部分。

## 11月5日发生了什么变化

Google 表示，Gemini Omni 1.2 Flash 可以生成三至十五秒的原生短片。上一代 Omni 1.1 的时长上限是十秒。新模型还支持多轮对话式编辑，用户可以接连提出修改要求。

对制作短视频开头的人来说，多出的五秒可以用来交代主角，再把一个想法往前推进。开头能否因此更有力，仍取决于素材和编辑判断。

Google 称，每秒0.07美元的价格比 Omni 1.1 降低了30%。Google 还宣称，新模型更能遵循参考素材，生成内容也更连贯。换成日常说法，就是画面能否贴合提供的材料，以及画面里的元素能否前后一致。这些能力对 Robin 的编辑工作有多大用处，需要用 Robin 的实际资料来检验。

可以把价格变化想成印刷机的运转成本下降了：多印一页更便宜了。选哪篇故事、核实证据、把内容编排清楚、让读者愿意读，仍然需要人来做。

印刷机只是帮助理解出版流程的比喻。Google 的公告提供了产品说明和视频生成标价。要了解整个编辑流程，还得实际使用模型，记录投入的工作，并观察观众的反应。

于是，一个实际问题浮现出来：生成十五秒视频只要1.05美元时，昂贵的工作会落在哪里？

## 用一篇已有文章作为起点

Robin Xie 的公开个人网站 iamrobin.ai，通过受治理的每日编辑系统 Ouroboros 发布作品。2026年8月20日，Ouroboros 发表了一篇关于 Google 和 Marvell 的文章。文章在这次11月的模型发布之前已经完成，可以作为拟议实验的稳定素材。

实验设想是取用文章中已经公开、经过核实的事实，制作两个短视频开头。8月的原文将作为历史作品保留，也作为希望了解完整内容的读者的阅读去处。

第一个开头拟从数据中心的物理运作机制讲起，让观众先看懂这件事具体怎样发生。第二个开头拟从资本配置问题讲起：资金怎样投入，这项决定又意味着什么。

两个开头使用同一批来源材料。一个请观众先看“它怎样运作”，另一个请观众先想“为什么有人愿意为它花钱”。

在模型生成第一帧之前，编辑就得作出这些选择：哪个经过核实的细节足以撑起开头，新读者需要多少背景，十五秒里适合讲清哪一个想法。画面再抢眼，观众也可能看完仍说不清主题。财务问题即使讲得清楚，也可能需要一点物理背景，观众才能理解它。

拟议的比较会让事实材料包、视频总时长、目标观众、分发时段，以及邀请观众阅读原文的方式保持一致。这些共同条件有助于解读观众反应的差异；差异究竟由什么造成，仍需谨慎判断。

截至11月9日这项选题任务提出时，这仍是一套拟议方法。视频制作、观众测试和后续修订都属于未来工作。SunTV 是与这场讨论相关的研究和内容方向，在这里的角色也是前瞻性的。

## 把整笔成本记下来

把1.05美元放进一份真实的制作记录，这个价格才更有用。

纯粹举个算账的例子：编辑先生成四个十五秒版本，再从中选出一个。按公布的价格，累计生成六十秒，费用就是4.20美元。最终选用的视频只有十五秒，生成账单却包含四次尝试。

人的工作也该留下记录。准备资料花了多久？哪些输出需要编辑？哪些版本被弃用？核查来源时，有没有发现某个细节需要改动，或某段画面需要重做？

拟议实验会记录每次生成尝试、生成秒数、重试、弃用的输出、人工编辑时间和来源核查后的修正。事实核实、权利审查和分发，都在单次生成价格之外。弄清观众真正重视什么，也有成本。

制作时还要分清两类材料：生成的示意画面，以及能够佐证事实的报道材料。

生成图像可以帮助解释一种机制。实拍报道画面和来源文件则可以为已经发生的事提供证据。观众需要知道自己看到的是哪一类材料。因此，方案要求在制作记录中标明两者，并在需要时向观众作出可见披露。

这也是准确讲述故事的一部分。画面和文字一样会传达事实含义，核对这些含义需要编辑投入精力。

## 观众能告诉我们什么

等两个开头都制作完成并触达观众，比较才可以着手回答一个更具体的问题：面对这篇文章，这群观众更容易被哪种开头带入故事？

方案把结果分成三类。留存反映观众看了多久；点击率反映他们是否顺着邀请去读原文；有信息量的回复则可能显示他们理解了什么、哪里感到困惑，以及希望继续了解哪个问题。

三类结果可能指向不同方向。一个开头也许让人看得更久，另一个却带来更多原文读者。因此，每项结果都应分别保存，连同观众反馈和后续修改的理由一起记录。

目前，结果仍是开放的。Google 的发布公告说明了它宣称的能力和公布的价格；拟议的编辑实验则提供一种方法，用来研究这些能力在真实出版流程中可能发挥什么作用。

生成成本下降，可能让编辑有余力尝试更多开头。每增加一个开头，编辑仍得判断：哪项事实值得占据最初几秒，哪幅画面能忠实解释它，观众的什么反应才算有用？

最终最有启发性的记录，或许是把两件事并排放在一起：每个开头的完整制作成本，以及观众看完之后做了什么。1.05美元是这项调查的起始数字。故事的价值，还要沿着读者接下来的旅程继续观察。
