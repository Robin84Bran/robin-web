## 1. Frontier Models and Agents | Put business acceptance around computer use

Date: October 6, 2026.

**Fact:** OpenAI's Ironclad case study describes a way to place computer-use models inside enterprise workflows: execute UI steps within an explicit authorization boundary while retaining validation, approval and exception handling. It is a provider case study, not an independent test, and does not prove that Robin's account has the same capability. [OpenAI](https://openai.com/index/advancing-computer-use-with-ironclad/)

**Inference:** Faster clicking is not business completion. The useful unit of autonomy is an accepted outcome, measured with human intervention, recovery time, permission boundaries and total cost.

**Why Robin should care:** This turns model capability into an auditable delegation contract instead of relying on one polished demonstration.

**One Action:** Choose one read-only browser task with no outbound action, write five acceptance conditions first, then compare human and agent completion, interventions and recovery time.

**One Action:** Build an 890 MW milestone sheet separating contract, capital, approvals, construction, first delivery and measured grid capacity.
