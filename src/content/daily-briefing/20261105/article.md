## 1. Frontier models and agents｜DeepSeek Harness brings schedules and review into one workspace

Date: November 4, 2026.

**Fact:** DeepSeek published the DeepSeek Harness v0.2.2-rc.1 prerelease on GitHub. It unifies scheduled-task management, supports reusable or new sessions, and places local and pull-request diffs, check status and review comments in one change-request and worktree interface. The notes also add an `apply_patch` tool that is disabled by default and explain that some observation policies require explicit configuration. This remains a release candidate, with no public stability or unattended-completion measurement. [Official release notes](https://github.com/deepseek-ai/deepseek-harness/releases/tag/dsh-v0.2.2-rc.1)

**Inference:** Agent tools are becoming execution workspaces with schedules, change review and recoverable state. Productivity belongs in accepted outcomes, failure recovery and human-review time.

**Why Robin should care:** RobinOS creates value through recoverable long-running work. The candidate points toward a useful product shape, while its default-policy changes deserve isolated validation first.

**One Action:** Run one v0.2.2-rc.1 scheduled task in a credential-free isolated repository, recording acceptance, recovery and human-review minutes while leaving production configuration unchanged.
