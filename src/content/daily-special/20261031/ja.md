# Bitcoinへの資金流入が語る暗号資産市場の一面

資金は、いくつもの経路から暗号資産市場に入る。米国の証券取引所に上場するファンドを通じてBitcoinやEtherを買う投資家がいる。一方、ブロックチェーン上で流通する、米ドルに連動した「ステーブルコイン」と呼ばれるトークンを使う人もいる。ステーブルコインは支払いに使えるほか、取引と取引の間に保有する資金にもなる。これらの経路は、同じ金融市場の活動をそれぞれ異なる角度から映し出す。

この話に登場する主体の役割は、それぞれ違う。BitcoinとEtherは、二つの投資商品群の裏付けとなる資産だ。ファンドの運用会社は、証券口座を通じてそれらの商品を利用できるようにする。Farside Investorsは、商品に流入・流出する資金の推計値を公表している。別のデータ提供会社であるDefiLlamaは、ステーブルコインの推定流通額を追跡している。

これらの指標を並べると、より大きな問いが見えてくる。暗号資産をめぐる金融活動が拡大しているように見えるとき、その広がりはどこまで及んでいるのか。

この問いが、10月22日のDaily Specialを受けた今回の記事の背景にある。10月31日の朝までに、さらに一組の確定した数値が得られた。直近の共通期間に、Bitcoinファンドへの資金流入、Etherファンドへの資金流入、米ドル連動型ステーブルコインの流通額がそろって拡大したかを確かめるのが目的だった。

## 比較できる共通期間を探す

上場投資信託は通常ETFと略され、証券取引所で売買される商品を通じて投資家に資産への投資機会を提供する。現物Bitcoin商品や現物Ether商品は、裏付けとなる暗号資産への投資機会を持つ。Farsideの資金フロー推計値は、これら上場商品の設定と償還の差し引きを示す。プラスは純流入、マイナスは純流出を意味する。

ステーブルコインは別の角度から状況を示す。この場合、基準となる通貨である米ドルに価値を連動させるよう設計されたトークンだ。DefiLlamaは、追跡対象の資産全体について、流通している供給量のドル換算額を推計している。

日々の水量計が付いた二本の管と、水位計が付いた別の貯水池を想像してほしい。BitcoinとEtherのETFの数値は水量計に似ており、一定期間に流れた量を記録する。ステーブルコインの流通額は貯水池の水位計に似ており、ある時点の量を示す。三つとも拡大していれば、システムの複数の部分に拡大が及んだことを示唆するだろう。ただし、個々のドルがどう動いたかを追うには、別の種類の証拠が必要になる。

数値を比べる前に、日付をそろえる必要があった。

**2026年10月31日、香港時間09時20分**の調査締め切り時点で、Farsideの10月30日分の行はまだ入力途中だった。BitcoinとEtherの複数の商品には、欠損または未完成の項目を示すダッシュが表示されていた。Bitcoinの小計も、更新中に変わった。

そのため、10月30日は比較から外した。両方の表で、表示されたすべてのファンド欄に数値が入っている直近の五つの取引日は、**10月23日、26日、27日、28日、29日**だった。

これにより、ETFの数値には明確な対象期間を、ステーブルコインの流通額には対応する10月23日と29日の比較時点を設定できた。この二時点の比較は、暦日で6日間にまたがる。

## 異なる道筋をたどった二つのファンド群

対象期間の初日である10月23日金曜日、Bitcoin商品は推計**1億3,790万ドルの純流出**を記録した。Ether商品は逆方向に動き、**440万ドルの小幅な純流入**となった。

週末を挟むと、関係は逆転した。

10月26日月曜日には、Bitcoin商品に**1億1,030万ドル**が流入する一方、Ether商品からは**8,860万ドル**が流出した。火曜日はBitcoin商品にさらに**1億7,600万ドル**が流入し、Ether商品からは**6,020万ドル**が流出した。水曜日の数値は、それぞれ**1億3,730万ドルの流入**と**2,140万ドルの流出**だった。

10月29日木曜日が対象期間の最終日となった。Bitcoinへの流入は**1,720万ドル**に鈍化した。Etherの流出は**1億550万ドル**に達し、この五つの取引日で最大の1日当たりの流出となった。

日々の推計値を合計すると、中心となる結果は次のようになる。

| 指標 | 10月23～29日の結果 |
| --- | ---: |
| Bitcoin ETFの5取引日の純資金フロー | **＋3億290万ドル** |
| Ether ETFの5取引日の純資金フロー | **－2億7,130万ドル** |
| 両時点間の米ドル連動型ステーブルコイン流通額 | **－31億2,500万ドル、約1.03％減** |

日ごとの推移も重要だ。Bitcoinの合計がプラスになったのは、初日の流出に続いて4取引日連続で流入したためだ。Etherの合計がマイナスになったのは、初日の小幅な流入に続いて4取引日連続で流出したためだ。両商品群とも初日の後に方向が変わり、10月29日までその方向が続いた。

二つのETFの合計を合わせると、**3,160万ドルのプラス**になる。計算としては正しいが、その小さなプラスの数字は、両者の大きな違いを覆い隠す。Bitcoinの純流入の大部分は、Etherの純流出によって相殺された。

拡大がどれほど広がっているかを考えるうえでは、それぞれの合計のほうが多くを語る。勢いが二つの商品群のうち一方に集中していたことが分かるからだ。

## ステーブルコインの数値

三つ目の指標も下向きだった。

DefiLlamaの時系列データによると、米ドル連動型ステーブルコインの推定流通額は10月23日の**303,248,946,001ドル**から、10月29日の**300,124,090,437ドル**へ減った。減少額は**3,124,855,564ドル**、率にして約**1.0305％**だった。

ステーブルコインの流通額は、暗号資産をめぐる金融活動の別の部分を測るため、この数値は比較に文脈を加える。供給量の増加は、米ドル連動型トークンの利用拡大と整合しうる。供給量の減少は、追跡対象の資産全体で推定流通額が縮小したことを示す。

ただし、この数値が意味することは、その定義の範囲内にとどまる。どれだけの現金が取引の場に届いたか、保有者がトークンをどう使うつもりだったかを確かめるには、さらなる証拠が必要だ。同様に、ステーブルコイン流通額の減少分をETFの資金フローの合計に足すと、流通額の変化と、特定の二つの投資商品群への資金フローを混ぜることになる。

ここで有用なのは方向の比較だ。日付をそろえた対象期間では、Bitcoin ETFの資金フローはプラス、Ether ETFの資金フローはマイナスで、ステーブルコインの指標も縮小した。

## 確定した数値から分かること

今回の更新に先立つ問いは、確定したデータによって三つの指標すべての拡大が確認できるか、というものだった。この期間の答えは**方向の分岐**だ。一つは拡大し、二つは縮小した。

この結果を受けても、調査上の問いに付けられた従来の**HOLD**という状態は維持される。ここでのHOLDは、より広い範囲での確認がなお得られていないことを意味する。これは証拠の状態を表すもので、投資判断は別のプロセスに属する。

今回の更新で、小さいながらも重要な点が確定した。10月29日までの記入が完了した行により、日付を定めた比較が可能になり、以前の不完全な表示に伴う不確実性は解消された。この5取引日を通じてBitcoinには純流入があったが、ほかの二つの指標は異なる方向を示した。

数値は引き続き推計値である。Farsideは、自社の表がリアルタイムで自動生成され、誤りや不正確さが生じる可能性があると断っている。DefiLlamaの追跡対象範囲や過去データの分類も変わりうる。この記事では、日付をそろえた比較を調査締め切り時点に固定するため、保存された過去のステーブルコインの数値を使った。

ETFの5取引日とステーブルコインの二時点の数値から分かるのは、短い期間の状況だ。この傾向が続くかどうか、投資家の動機、将来の価格との関係は、いずれも未解明である。

現時点で確定した全体像の中では、Bitcoinへの資金流入を適切な位置に置ける。暗号資産をめぐる金融活動の一つの経路では明確なプラスが見られた一方、Etherファンドからは資金が流出し、流通する米ドル連動型トークンの総額も縮小した。次に問うべきは、これらの方向が収束し始めるかどうかだ。
