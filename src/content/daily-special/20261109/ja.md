# 暗号資産の3つの指標がそろって低下

暗号資産市場には、いくつもの経路を通じて資金が入ってくる。米国の証券取引所で上場商品の持分を買い、ビットコインや、イーサリアムのネットワークで使われる資産であるイーサへの投資を行う人もいる。一方、ドルに連動するデジタルトークン「ステーブルコイン」を保有する人もいる。ステーブルコインは暗号資産サービスの間を移動でき、支払いや取引の手段として使われる。

これらの経路には、それぞれ異なる記録が残る。上場商品は、アナリストが資金の流入・流出を推計するための情報を公表している。ステーブルコインのデータ提供者は、流通するトークンの推計価値を追跡している。これらの記録を合わせると、市場への参加がどう変化しているか、その一端が見えてくる。

2026年11月9日に調べた直近の完了週では、選んだ3つの指標が同じ方向を示した。米国上場のビットコイン商品は、推計で資金の純流出となった。イーサ商品も同様だった。米ドルに連動するステーブルコインの推計流通額も、ドル換算で減少した。

3つの方向がそろった点は、10月31日に公表した前回の比較からの変化だ。前回は、ビットコイン商品への資金流入と、イーサ商品からの資金流出、ステーブルコイン流通量の縮小が併存していた。今回は、縮小が3つの指標すべてに広がった。

この変化が意味を持つのは、資金の再投入を検討するために提案された投資判断の確認条件が、これらの経路で縮小が止まるのを待っていたからだ。その条件から何が読み取れるのかを理解するには、まず各指標が何を測っているのかを押さえる必要がある。

## 2本のパイプと1つの貯水池

ビットコインやイーサの上場商品を使うと、投資家は取引所で売買される持分を通じて、原資産への投資ができる。その持分を支えているのが、商品と直接取引することを認められた企業である「指定参加者」による、持分の設定・償還の仕組みだ。

2025年7月、米国証券取引委員会（SEC）は、暗号資産の上場商品について、*現物による*設定・償還を承認した。平たく言えば、この手続きで原資産の暗号資産を引き渡したり、受け取ったりできるということだ。そのため、商品の資金フローに付されるドル額は、設定・償還の仕組みを通じて動く資産の価値を表す場合がある。

Farside Investorsは、こうした日々のフローの推計値を自動更新して公表している。プラスの数値は推計純流入、マイナスの数値は推計純流出を示す。数値が表すのは、商品単位での動きだ。最終的な投資家が誰なのか、なぜ行動したのか、償還された資産がその後どこへ向かったのかは、それぞれ別途確かめる必要がある。

ステーブルコインからは、別の側面が見える。これは米ドルなどの参照資産に連動するよう設計されたデジタルトークンだ。DefiLlamaはその推計流通額を追跡し、ステーブルコインの時価総額を、流動性、信頼、普及度を示す代理指標と位置づけている。代理指標とは、観測できるものを通じて、ある状態を間接的に捉える尺度である。

たとえ話を使うと、違いがわかりやすい。2本のパイプに取り付けられた流量計と、それらとは別の貯水池にある水位計を想像してほしい。パイプの流量計は、1週間にどれだけの水が流れ込んだか、流れ出たかを記録する。貯水池の水位計は、2つの時点でそれぞれどれだけの水があったかを記録する。

ここで2本のパイプに当たるのが、ビットコイン商品とイーサ商品だ。貯水池はステーブルコインの流通量に当たる。3つとも低下していれば、測定対象の経路で縮小がより広く起きていることがうかがえる。ただし、それぞれの計器が測る配管系統は異なる。貯水池の減少分をパイプの流量に足せば、異なる測定値を混ぜることになる。また、特定の資金がそれらの間をどう動いたかを追うには、追加の証拠が必要になる。

## 減少した1週間の途中にあった、小さな持ち直し

商品フローの集計期間は、11月2日から6日までの米国市場の5営業日だ。調査の締め切りである11月9日午前9時11分（香港時間）の時点では、Farsideのビットコインとイーサの表で、この期間に表示された各商品のセルすべてに数値が入っていた。

週の始まりは、両グループとも推計純流出だった。11月2日月曜日には、ビットコイン商品で3億9,860万ドル、イーサ商品で1億3,970万ドルが流出した。火曜日も、それぞれ1億1,560万ドル、8,530万ドルの流出が続いた。

水曜日には、その流れが一度途切れた。ビットコイン商品には推計7,460万ドル、イーサ商品には5,300万ドルの純流入があった。このプラスの日は、週の途中の経過を知るうえで意味がある。週全体では減少していても、その間に持ち直す場面はある。

木曜日と金曜日には、流出が再開した。この2営業日で、ビットコイン商品はさらに推計8億4,210万ドル、イーサ商品は1億9,320万ドルの純流出となった。

5営業日全体の合計は次のとおりだ。

| 商品グループ | 週間推計純流出額 |
| --- | ---: |
| ビットコイン商品 | 12億8,170万ドル |
| イーサ商品 | 3億6,520万ドル |
| 合計 | 16億4,690万ドル |

2つのグループを合わせると、**推計純流出額は約16億4,700万ドル**となった。水曜日の流入が週間の減少を和らげ、残る4営業日の流出が週全体の方向を決めた。

ステーブルコインの比較には、近接する暦日である11月1日と11月8日を用いた。この7日間で、DefiLlamaが追跡する米ドル連動型ステーブルコインの推計流通額は、ドル換算で約**2,983億8,500万ドルから2,932億3,700万ドル**へ減少した。

減少幅は約**51億4,800万ドル、率にして1.7253%**だ。

この数値には、押さえておくべき細部がある。DefiLlamaのエンドポイントには、額面ベースの流通量の系列と、ドル換算した価値の系列の両方が含まれる。額面ベースの系列では、約51億6,300万単位の減少だった。今回の比較では、以前に公表した方法に合わせてドル換算の系列を使っており、減少額は51億4,800万ドルとなる。この2つの系列を区別することで、週をまたいだ比較の一貫性を保っている。

商品フローとステーブルコインの推計値では、時間の区切りも異なる。一方は株式市場の5営業日を対象とし、もう一方は暦日で7日間の流通額を比較している。両者が同じ方向を示したことから、近接した期間での動きの方向について述べることができる。

## 提案された確認条件から、実際に何がわかるのか

この背景を踏まえると、問いは明確になる。資金の再投入を検討するために提案された条件は、満たされたのだろうか。

確認条件は2つある。まず、ビットコイン商品とイーサ商品の双方で、週間フローが純流出の状態を脱すること。次に、対応する7日間のステーブルコイン供給量の指標で、縮小が止まることだ。

11月9日の締め切り時点では、**提案された確認条件は引き続き充足待ちだった**。両商品グループの週間フロー合計はマイナスで、ステーブルコインのドル換算推計額も減少していた。

今回の新たな観測で意味があるのは、縮小の広がりだ。10月31日の比較では、ビットコイン商品がプラスを示す一方、残る2つの指標は低下していた。直近の期間では、3つとも下向きになった。したがって、この確認条件が対象とする指標すべてで縮小が起きていたことになる。

この結論が示す範囲は明確だ。選んだルールに照らして、直近の完了期間がどうだったかを述べている。そのルールが投資成果を改善するかどうかは、さらに調べるべき研究上の問いとなる。答えるには、条件が満たされた後に何が起きたか、その結果が別の手法と比べてどうだったかも含め、複数の期間を通じた証拠が必要だ。

今回の数値には、いくつもの説明の余地も残る。商品の償還は、投資家のさまざまな判断から生じうる。ステーブルコインの流通額は、追跡対象のトークンの推計残高を反映しており、そこには独自の発行、償還、価値評価の動きがある。共通の原因を確かめたり、同じ資金がこれらの経路をどう通ったかを追ったりするには、追加の記録が必要になる。

情報源の品質も、結論に時点と範囲を明示する理由になる。Farsideは、自動生成される表に誤りや不正確な情報が含まれる可能性があると述べている。今回の調査では、表示された行とその計算を確認した。発行体の記録から独立に数値を再構成すれば、より深い検証ができる。DefiLlamaの過去データの収録範囲や分類は変更されることがあり、その流通額の推計は、市場の流動性を間接的に捉えるものである。

こうした留保を明確にすることで、観測の価値を保つことができる。選んだ指標の範囲では、この週の結果は明瞭だった。ビットコイン商品とイーサ商品では推計純流出があり、ステーブルコインのドル換算額も縮小した。この調査は、公開情報に基づく観測として行われ、金融取引の執行とは区別されている。

次の完了期間には、この足並みが続くのか、反転するのか、それとも再び方向が分かれるのかが見えてくる。今のところ読み取れるのは、測定した3つの経路へ縮小が広がったということだ。そして、それがいつまで続くのかという問いは、開かれたままである。
