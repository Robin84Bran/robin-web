# 加密市场的三项指标一同转降

资金通过多条路径进入加密市场。一些投资者在美国证券交易所买入相关产品的份额，借此参与比特币或以太币的价格变动；以太币是以太坊网络使用的资产。另一些人持有与美元挂钩的数字代币，也就是稳定币。这些代币可以在不同加密服务之间流转，用于支付或交易。

不同路径留下的记录也各不相同。交易所交易产品会发布相关信息，分析师据此估算流入和流出产品的资金。稳定币数据提供方则追踪流通中代币的估算价值。将这些记录放在一起，可以从部分侧面观察市场参与情况如何变化。

在2026年11月9日考察的最近一个完整周内，选取的三项指标指向同一个方向：美国上市的比特币产品录得估算净流出，以太币产品也录得估算净流出，与美元挂钩的稳定币流通美元价值估计值同样下降。

与10月31日发布的上一次比较相比，这种一致性标志着变化。当时，比特币产品仍有资金流入，而以太币产品资金流出、稳定币流通规模收缩。这一次，收缩扩展到了全部三项指标。

这一变化之所以值得关注，是因为一项拟议的投资检查规则要求先等这些渠道停止收缩，再考虑让资金重新入场。要理解这项检查能告诉我们什么，首先需要弄清每项指标衡量的内容。

## 两根水管与一座水库

比特币或以太币交易所交易产品，让投资者可以通过在交易所买卖份额，获得对底层资产的敞口。这些份额背后有一套申购和赎回机制，由获准直接与产品开展交易的机构——授权参与者——创建或赎回份额。

2025年7月，美国证券交易委员会批准加密资产交易所交易产品采用*实物*申购和赎回。用日常语言来说，这意味着在这一过程中可以交付或接收底层加密资产。因此，产品流量中以美元表示的数字，可以代表通过产品申购和赎回机制转移的资产价值。

Farside Investors发布自动更新的每日流量估算。正数表示估算净流入，负数表示估算净流出。这些数字描述的是产品层面的活动。最终投资者的身份、采取行动的原因，以及赎回资产此后的去向，都需要另行探究。

稳定币提供了另一个观察角度。这类数字代币的设计目标，是跟踪美元等参照资产的价值。DefiLlama追踪稳定币的估算流通价值，并将稳定币市值描述为衡量流动性、信任和采用程度的代理指标。所谓代理指标，就是通过可观察的事物，间接了解某种状况。

用一个比喻，更容易看清两者的区别。想象两根水管各装有一只流量计，另有一座独立的水库装着水位计。水管流量计记录一周内流入或流出了多少水，水库水位计则记录两个时间点各有多少水。

这里，两根水管代表比特币和以太币产品，水库代表稳定币的流通规模。三项读数同时下降，意味着所衡量的渠道出现了更广泛的收缩。不过，每项指标仍属于各自的管路系统。把水库减少的水量与水管流量相加，会混合不同的测量口径；要追踪特定资金如何在它们之间流转，则需要更多证据。

## 下行一周中的短暂回升

产品流量的观察窗口涵盖11月2日至6日的五个美国交易日。截至研究截止时间，即11月9日香港时间09:11，Farside的比特币和以太币表格中，这些日期下显示的每一个产品单元格都已有数字。

这一周以两类产品的估算净流出开场。11月2日星期一，比特币产品录得3.986亿美元流出，以太币产品录得1.397亿美元流出。星期二，两者继续流出，金额分别为1.156亿美元和8,530万美元。

星期三，这一走势出现了短暂转折。比特币产品吸引了估算净流入7,460万美元，以太币产品吸引了5,300万美元。这一天的正向读数值得保留，因为它呈现了周内的变化路径：一周整体下降，途中也可以出现回升。

星期四和星期五，资金再次流出。这两个交易日合计，比特币产品又录得8.421亿美元的估算净流出，以太币产品则录得1.932亿美元。

完整五个交易日的合计如下：

| 产品类别 | 估算周度净流出 |
| --- | ---: |
| 比特币产品 | 12.817亿美元 |
| 以太币产品 | 3.652亿美元 |
| 合计 | 16.469亿美元 |

两类产品合计录得约**16.47亿美元的估算净流出**。星期三的流入缓和了全周的降幅，其余四个交易日则决定了整体方向。

稳定币的比较采用了相邻的自然日端点：11月1日和11月8日。在这七天里，DefiLlama所追踪的美元挂钩稳定币，其估算流通美元价值从约**2,983.85亿美元降至2,932.37亿美元**。

降幅约为**51.48亿美元，即1.7253%**。

这个数字背后有一个重要细节。DefiLlama的数据接口同时提供名义流通量序列和以美元计价的序列。名义流通量序列减少了约51.63亿个单位。本次比较沿用此前公布的方法，采用美元计价序列，得出51.48亿美元的降幅。明确区分这两个序列，才能保持各周比较口径的一致。

产品流量与稳定币估算的时间口径也有所不同。前者涵盖五个股市交易日，后者比较七个自然日之间的流通规模变化。两者方向一致，支持我们对相邻时间窗口内的变化方向作出判断。

## 这项拟议检查究竟回答什么

有了上述背景，问题就很明确了：考虑让资金重新入场的拟议条件，是否已经满足？

这项拟议检查包括两部分。第一，比特币和以太币产品的周度资金流都应停止收缩。第二，与之对齐的七日稳定币供应量指标也应停止收缩。

截至11月9日的研究截止时间，**这项拟议检查仍有待满足**。两类产品的周度资金流合计均为负值，稳定币的美元价值估计值也有所下降。

这次有价值的新观察，在于收缩的范围。10月31日的比较中，比特币产品提供了一个正向读数，另外两项指标下降。在最新窗口中，三项读数全部向下。因此，这项拟议检查所选取的每一项指标，都出现了收缩。

这一结论的适用范围很明确：它描述了最近一个完整窗口的表现，与某项选定规则之间的对应关系。至于这项规则能否改善投资结果，仍是一个需要进一步研究的问题。要回答它，需要考察多个时期的证据，包括条件满足之后发生了什么，以及这些结果与其他方法相比如何。

当前数字也容纳了多种解释。产品赎回可能源于不同的投资者决策。稳定币流通规模反映的是所追踪代币的估算存量，有其自身的发行、赎回和估值变化机制。要确定一个共同原因，或追踪同一笔资金在这些渠道中的流转，还需要额外记录。

数据来源的质量，也要求结论保留明确的日期和范围。Farside表示，其自动生成的表格可能含有错误或不准确之处。本次研究检查了显示的数据行及其算术关系；如果能依据发行方记录独立重建数据，就能作更深一层的核实。DefiLlama的历史数据覆盖范围和分类可能发生变化，其流通规模估计也始终只是观察市场流动性的间接视角。

这些限定让观察本身的价值更加清晰。在选定的指标范围内，这一周给出了明确结果：比特币产品估算净流出、以太币产品估算净流出，稳定币的美元价值也在收缩。这项研究始终是一项基于公开来源的观察，与金融交易执行保持区分。

下一个完整窗口将显示，这种一致性会延续、逆转，还是重新呈现涨跌交错的局面。眼下，三个受测渠道的收缩范围正在扩大，而它会持续多久，仍是一个开放的问题。
