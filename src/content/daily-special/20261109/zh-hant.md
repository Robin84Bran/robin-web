# 三項加密資產指標同步回落

資金透過多條途徑進入加密資產市場。有些投資者在美國證券交易所買入產品份額，藉此取得比特幣或以太幣的投資敞口；以太幣是以太坊網絡使用的資產。另一些人持有稱為穩定幣、與美元掛鈎的數碼代幣。這些代幣可以在不同加密資產服務之間轉移，用於支付或交易。

這些途徑留下的紀錄各有不同。交易所買賣產品公布的資料，讓分析員可以估算流入和流出產品的資金；穩定幣數據供應商則追蹤流通中代幣的估計價值。兩類紀錄合起來，讓我們從部分角度觀察市場參與情況的變化。

在截至2026年11月9日檢視的最近一個完整星期，三項選定指標指向同一方向。美國上市的比特幣產品錄得估計淨流出，以太幣產品亦然。與美元掛鈎的穩定幣，其估計流通美元價值也有所下降。

這種一致走勢，與10月31日發表的上一次比較有所不同。當時，比特幣產品錄得資金流入，同期以太幣產品錄得流出，穩定幣流通規模也在收縮。這一次，收縮擴展至全部三項指標。

這個變化之所以重要，是因為一項擬議中的投資檢視準則，要求這些渠道先停止收縮，才考慮重新投入資金。要理解這項準則能告訴我們甚麼，先要弄清楚各項指標量度的是甚麼。

## 兩條水管與一個水庫

比特幣或以太幣交易所買賣產品，讓投資者透過在交易所買賣的份額，取得相關資產的投資敞口。這些份額背後有一套機制，讓獲准直接與產品交易的機構，即認可參與者，創設或贖回份額。

2025年7月，美國證券交易委員會（SEC）批准加密資產交易所買賣產品採用*實物*創設及贖回。用日常語言說，就是容許參與者在這個過程中交付或收取相關加密資產。因此，產品流量所附的美元數字，可以代表透過產品創設及贖回機制轉移的資產價值。

Farside Investors 發布自動更新的每日流量估算。正數表示估計淨流入，負數表示估計淨流出。這些數字描述的是產品層面的活動。最終投資者的身分、他們採取行動的原因，以及贖回資產其後流向何處，則是需要另行探究的問題。

穩定幣提供另一個觀察角度。這類數碼代幣的設計目標，是追蹤美元等參考資產的價值。DefiLlama 追蹤其估計流通價值，並將穩定幣市值形容為流動性、信任及採用程度的代理指標。代理指標是一種間接量度方式：透過可觀察的事物，幫助我們了解某種狀況。

用一個比喻，兩者的分別會更清楚。想像兩條水管各裝有流量計，另一個獨立水庫則裝有水位計。水管的流量計記錄一星期內有多少水流入或流出；水庫的水位計則記錄兩個時間點各有多少存水。

在這個比喻中，兩條水管代表比特幣及以太幣產品，水庫代表穩定幣的流通規模。三項讀數一同下降，意味所量度的渠道出現較廣泛的收縮。每個儀表仍然屬於各自的供水系統。把水庫存水量的跌幅加到水管流量上，會混合不同的量度；若要追蹤特定資金如何在兩者之間流轉，則需要更多證據。

## 下跌的一星期中，曾有短暫回升

產品流量的觀察期涵蓋11月2日至6日五個美國交易日。截至香港時間11月9日上午09:11的研究截點，Farside 比特幣及以太幣表格中，這些日期所顯示的每個產品欄位都有數字。

星期初，兩組產品均錄得估計淨流出。11月2日星期一，比特幣產品流出3.986億美元，以太幣產品流出1.397億美元。星期二，兩者再分別流出1.156億美元及8,530萬美元。

星期三打斷了這個走勢。比特幣產品錄得估計淨流入7,460萬美元，以太幣產品則流入5,300萬美元。這個錄得正數的交易日值得留意，因為它呈現了星期內的變化路徑：全星期下跌，途中仍可出現回升。

星期四及星期五再度出現流出。這兩個交易日合計，比特幣產品再錄得估計淨流出8.421億美元，以太幣產品則流出1.932億美元。

五個交易日的合計數字如下：

| 產品類別 | 全星期估計淨流出 |
| --- | ---: |
| 比特幣產品 | 1,281.7百萬美元 |
| 以太幣產品 | 365.2百萬美元 |
| 合計 | 1,646.9百萬美元 |

兩組產品合共錄得約 **16.47億美元的估計淨流出**。星期三的流入減輕了全星期的跌幅，其餘四個交易日則決定了整體方向。

穩定幣的比較採用相近日曆日期作為起訖點：11月1日及11月8日。在這七天之間，DefiLlama 所追蹤、與美元掛鈎的穩定幣，其估計流通美元價值由約 **2,983.85億美元降至2,932.37億美元**。

即減少約 **51.48億美元，跌幅為1.7253%**。

這個數字背後有一項重要細節。DefiLlama 的數據端點同時提供按名義單位計算的流通量序列，以及按美元計值的序列。名義流通量序列減少約51.63億個單位。本次比較沿用先前公布的方法，採用美元計值序列，因此得出51.48億美元的跌幅。清楚區分這兩組序列，才能讓不同星期的比較保持一致。

產品流量與穩定幣估算採用的時間尺度也有分別。前者涵蓋五個證券市場交易日，後者則比較相隔七個曆日的流通規模。兩者走勢一致，支持我們描述這些相近觀察期的共同方向。

## 擬議準則實際回答甚麼問題

有了上述背景，問題就很清楚：考慮重新投入資金的擬議條件，是否已經達成？

這項擬議準則分為兩部分。首先，比特幣及以太幣產品的每周資金流均應停止收縮。其次，時間上相配的七天穩定幣供應量指標也應停止收縮。

截至11月9日的研究截點，**擬議準則的條件仍有待達成**。兩組產品的每周資金流合計均為負數，穩定幣的美元價值估算也有所下降。

這次有用的新觀察，在於收縮的廣度。10月31日的比較中，比特幣產品錄得正數，其餘兩項指標則下跌。最新觀察期內，三項讀數全部向下。因此，擬議準則所涵蓋的每一項選定指標，都出現了收縮。

這個結論有明確的適用範圍：它描述最近一個完整觀察期的情況，與一項選定規則如何對照。這項規則能否改善投資結果，則是另一個有待研究的問題。要回答它，需要多個時期的證據，包括條件達成後發生了甚麼，以及結果與其他做法相比如何。

目前的數字也容許多種解釋。產品贖回可能源於不同的投資者決定；穩定幣流通規模反映的是所追蹤代幣的估計存量，當中有其自身的發行、贖回及估值變化。要確認共同成因，或追蹤同一筆資金在這些渠道之間的流向，都需要額外紀錄。

資料來源的質素，也說明結論需要保留明確日期及具體範圍。Farside 表示，其自動生成的表格可能含有錯誤或不準確之處。本次研究核對了表格顯示的各行數據及其計算；若能根據發行機構的紀錄獨立重建數據，便可提供更深入的驗證。DefiLlama 的歷史數據涵蓋範圍及分類可能改變，而其流通規模估算始終是觀察市場流動性的間接方式。

這些限定讓觀察的價值得以保留。在選定指標的範圍內，這一星期呈現了清晰結果：比特幣產品錄得估計淨流出、以太幣產品錄得估計淨流出，穩定幣的美元價值亦告收縮。這項研究維持在公開資料觀察的層面，與金融交易執行分開。

下一個完整觀察期，可以顯示這種一致走勢會持續、逆轉，還是再度變成方向不一的局面。目前，故事所呈現的是三個受量度渠道的收縮範圍擴大；至於這種情況會持續多久，問題仍然敞開。
