2033年の1メガワットは、遅れて届く2027年の1メガワットではない。顧客が必要としていたのが2027年の電力なら、それは別の商品だ。

この違いは、ロンドン近郊の Loughton で計画されたAIスーパーコンピューターの物語に隠れている。

2025年9月、Microsoft は英国に300億ドルを投資し、Nscale とともに23,000基を超える Nvidia GPU を使った国内最大のスーパーコンピューターを建設すると発表した。1か月後、Nscale は約束の輪郭を示した。初期50メガワット、90MWまで拡張可能な施設に約23,000基の GB300 GPU を置き、2027年第1四半期から Microsoft Azure にサービスを提供する計画だった。

数字は大きかった。しかし、本当の商品は日付だった。

2026年10月、Guardian は、想定される系統電力の時期が2030年代前半から半ばへ移った後、Microsoft が Loughton の契約から撤退したと報じた。Nscale はサイトへの関与を続け、代替案を探すと述べた。それでも、当初の顧客ウィンドウと報じられた電力ウィンドウは、もう重なっていなかった。

![2027年の顧客ウィンドウと2030年代前半から半ばの系統電力ウィンドウが、重ならない二つの時間軸に置かれている。](/binary-stories/the-megawatt-had-a-deadline/hero.webp)

## 容量は条件の組み合わせである

私たちはインフラを名詞で語りがちだ。50MW、23,000基のGPU、ひとつのキャンパス。

しかし、使える容量は条件の組み合わせだ。

**必要な電力 × 必要な場所 × 顧客がまだ必要としている時間**

どれか一つを外せば、見出しは残ってもサービスは消える。

倉庫にあるGPUは計算能力ではない。電力が来てもシステム全体のコミッショニングが終わっていない建物は計算能力ではない。顧客のロードマップが変わった後に稼働するシステムも、元の売上とは別物だ。物理資産には価値が残るかもしれないが、経済への道筋は変わっている。

だから時間は容量の脚注ではない。場所とメガワットだけでは足りない。日付も単位に含める必要がある。

## 五つの動詞、五つの異なるリスク

一つの容量見出しを五つの動詞に分けると、Loughton の物語は読みやすくなる。

**発表 → 契約 → 受電 → コミッショニング → 売上化**

各段階は異なる問いに答える。

発表は計画があるかを問う。契約は顧客が署名したかを問う。受電は必要な規模の電力がサイトに届くかを問う。コミッショニングは電気、冷却、ネットワーク、計算システムが一体で動くかを問う。売上化は顧客が合意した条件でサービスを受けているかを問う。

一つの動詞を飛ばしても、次の動詞が早く来るわけではない。

Nscale の2026年9月の提出書類は、この区別を明確にした。active のGPUは約25,000基、active と contracted の合計は約461,000基。サイトは5か所が active、12か所が contracted だった。active の総契約価値は26億ドル、active と contracted の合計は1,034億ドルだった。

この差は、契約済みプロジェクトが失敗する証拠ではない。「契約済み」と「稼働中」が別の状態だという証拠だ。Nscale は active をオンラインで売上を生む容量と定義した。顧客の署名は需要の証拠ではあるが、最後のラックまで最後の電力が届いた証拠ではない。

## 四つの時計を一枚に置く

有用な計画対象は容量の総数ではなく、時計の地図だ。

Loughton の顧客時計は2027年第1四半期を指していた。報じられた系統時計は2030年代前半から半ばを指した。Nscale 全社の設備・建設コミットメントは主に2026年と2027年に支払われ、少なくとも31億ドルの転換社債は、早期に転換または買い戻されなければ2028年6月に満期を迎える。

公開記録から、これら全社の義務を Loughton に割り当てることはできない。同じページに置く理由は、時間の整合がなぜ重要かを示すためだけだ。サイトの遅延、ハードウェア注文、資金調達の満期、顧客の締切は交換可能な日付ではない。衝突しうる別々の時計だ。

大規模なAI容量の発表には、まず四つの質問を置ける。

1. 必要な規模の系統電力は、契約上いつ利用できるのか。
2. 機器の納入ではなく、システム全体のコミッショニングはいつ終わるのか。
3. 顧客のワークロードとハードウェア計画は、いつまで待てるのか。
4. 最初の三つの日付が離れたとき、どの義務を動かせるのか。

GPUの数は、その後に聞くべきだ。

## サイトが残っても、販売機会は失効する

Nscale の現在のインフラページは、Loughton を90MWまで電力配分を拡大できるキャンパスとして掲載している。同社は Guardian に、代替電源や英国の別サイトを検討中で、Microsoft とのより広い関係には影響しないと説明した。

土地、設計、別の顧客には将来が残るかもしれない。しかし、元の2027年の重なりは戻らない。

インフラは長く残っても、需要には期限がある。サイトは数十年使えるかもしれない。特定顧客の納期ウィンドウは数四半期で閉じることがある。

ここに Loughton の反転がある。希少だったのは単なる電力ではない。この構成、この場所、この予定を顧客がまだ必要としている間に届く電力だった。

次にAIプロジェクトがGPUとメガワットを掲げたら、欠けた単位を足したい。

問いは、**いつまでに？**

日付のない容量主張は、まだ完成していない。
